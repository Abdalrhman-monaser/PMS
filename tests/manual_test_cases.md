# مصفوفة وسيناريوهات التحقق الوظيفي واختبار الصلاحيات (QA & RBAC Acceptance Report)

**نطاق الاختبار**: التحقق الشامل من منظومة المصادقة (Authentication)، إدارة الجلسات (Session Management)، ومصفوفة التحكم في الوصول المبني على الأدوار (Role-Based Access Control - RBAC).  
**البيئة**: PHP 8.2 / Apache (XAMPP) / MySQL  
**الإصدار المستهدف**: PMS Release Candidate (RC-M6)

---

## 1. مصفوفة الصلاحيات المعتمدة (RBAC Matrix)

| الوحدة / الإجراء | المدير العام (Admin) | مدير المشروع (Project Manager) | عضو الفريق (Team Member) | الزائر (Guest / Unauthenticated) |
| :--- | :---: | :---: | :---: | :---: |
| **لوحة التحكم (Dashboard)** | مسموح (كامل) | مسموح (محدود) | مسموح (محدود) | محظور (إعادة توجيه للـ Login) |
| **إدارة المشاريع (إضافة/تعديل)** | مسموح | مسموح (مشاريع مخصصة) | قراءة فقط | محظور (403 / Redirect) |
| **حذف المشاريع والمهام** | مسموح | محظور | محظور | محظور |
| **إدارة المستخدمين والصلاحيات** | مسموح | محظور | محظور | محظور |
| **الوصول لواجهة البرمجة (REST API)** | مسموح (بـ Bearer Token) | مسموح (بـ Bearer Token) | مسموح (بـ Bearer Token) | محظور (401 Unauthorized) |

## 2. جدول سيناريوهات الاختبار اليدوي (Manual Test Cases)

| المعرف (ID) | عنوان الاختبار (Test Scenario) | الخطوات المتبعة (Execution Steps) | النتيجة المتوقعة (Expected Result) | حالة الاختبار (Status) |
| :--- | :--- | :--- | :--- | :---: |
| **TC-AUTH-01** | تسجيل دخول ناجح بحساب صحيح | 1. الانتقال لـ `/login.php`<br>2. إدخال بريد وكلمة مرور صحيحة<br>3. النقر على "دخول" | إنشاء Session آمنة، التوجيه لـ `dashboard.php` مع ظهور اسم المستخدم | **Passed** |
| **TC-AUTH-02** | محاولة دخول ببيانات خاطئة | 1. إدخال كلمة مرور خاطئة<br>2. النقر على "دخول" | رفض الدخول، بقاء المستخدم في نفس الصفحة مع رسالة خطأ واضحة | **Passed** |
| **TC-AUTH-03** | تسجيل الخروج وتدمير الجلسة | 1. النقر على زر "تسجيل الخروج"<br>2. محاولة الرجوع عبر زر المتصفح (Back) | تدمير الجلسة بالكامل (`session_destroy`)، منع الوصول للوحة التحكم وإعادة التوجيه لـ `/login.php` | **Passed** |
| **TC-SEC-01** | منع وصول الزائر للصفحات الإدارية | طلب الرابط المباشر `modules/settings/permissions.php` دون تسجيل دخول | اعتراض الطلب تلقائياً وإعادة التوجيه إلى `login.php?error=unauthorized` | **Passed** |
| **TC-RBAC-01** | عزل صلاحيات الإعدادات والحذف | تسجيل الدخول بحساب مستخدم عادي ومحاولة فتح مسار إعدادات الصلاحيات | إظهار رسالة رفض الصلاحية كود 403 Forbidden أو إعادة التوجيه لصفحة لوحة التحكم | **Passed** |
| **TC-API-01** | التحقق من المصادقة في الـ API | طلب نقطة النهاية `GET /api/tasks` دون ترويسة `Authorization` | استقبال استجابة JSON بكود `401 Unauthorized` ورسالة `Missing Bearer token` | **Passed** |
| **TC-API-02** | استرجاع المهام برمز دخول صحيح | طلب `GET /api/tasks` مع إرسال ترويسة `Authorization: Bearer <valid_token>` | استقبال استجابة JSON بكود `200 OK` تحوي قائمة المهام بصيغة معيارية | **Passed** |

## 3. التوصيات والإجراءات التصحيحية
- التأكد من تجديد معرّف الجلسة (`session_regenerate_id(true)`) عند كل عملية تسجيل دخول لمنع هجمات Session Fixation.
- تطبيق التحقق الصارم من توكن CSRF على جميع نماذج التعديل والحذف.
